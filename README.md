# Sabor Express

Aplicação de terminal em Python para gerenciar restaurantes, desenvolvida durante o curso de Python da Alura.

## Funcionalidades

- **Cadastrar restaurante**: informe o nome e a categoria (novos restaurantes começam como inativos)
- **Listar restaurantes**: exibe nome, categoria e status de cada restaurante
- **Alterar status**: alterna um restaurante entre ativo e inativo
- **Sair**: encerra a aplicação

## Conceitos praticados

- Listas e dicionários
- Funções e docstrings
- `match`/`case` e tratamento de exceções com `try`/`except`
- f-strings e formatação de texto com `ljust`
- Uso do módulo `os`

## Como executar

Requisitos: Python 3.12 ou superior, no Windows (a limpeza de tela usa `cls`).

```bash
python app.py
```
